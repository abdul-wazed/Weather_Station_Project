<h1>Weather Station (Pico + Node.js Dashboard)</h1> <p> This project is an end-to-end IoT weather station. A Raspberry Pi Pico reads environmental sensors, displays live values on an OLED, and periodically uploads readings to a Node.js backend over Wi-Fi. The backend stores data locally in SQLite, syncs to Firebase Realtime Database, and exposes REST APIs for a web dashboard and historical charts. When readings cross configured thresholds, the server can send WhatsApp alerts via CallMeBot. </p> <hr/> <h2>Features</h2> <ul> <li>Live sensor readings: temperature, humidity, wind speed (simulated), and noise level.</li> <li>OLED display on the device for real-time feedback.</li> <li>Automatic upload to backend every 5 seconds via HTTP POST.</li> <li>Local persistence using SQLite and cloud sync using Firebase.</li> <li>Dashboard APIs for latest values and history/trends.</li> <li>WhatsApp alerting based on safe-limit thresholds.</li> <li>Optional global weather lookup through OpenWeather API.</li> </ul> 
</p> <hr/> <h2>Project Structure</h2> <h3>1) Firmware (WEATHER_STATION_PICO)</h3> <pre> WEATHER_STATION_PICO/ ├─ platformio.ini └─ src/ ├─ main.cpp # sensor read, JSON build, Wi-Fi + HTTP POST ├─
